# 📈 台灣鐵路四界行 — 專案優化與重構日誌

本文件詳細記錄了「台灣鐵路四界行」台語交通教學 WebApp 專案在介面美學、效能、可接近性、台語語音口語化與教育互動性等層面的優化歷程。

---

## 🎨 1. 介面美學與使用者體驗 (UI/UX) 優化

### 漸層配色與深色模式
* **優化前**：原本網頁使用單純的純綠色頂欄 (`#6BCB77`) 與土黃色按鈕，色彩飽和度高，視覺上較為生硬，且不支援深色主題。
* **優化後**：
  * 引進雙主題色系 (Light / Dark)。使用 CSS 變數定義 `data-theme`，讓背景在柔和的「陽光海洋藍漸層」與「極光黑夜藍」之間流暢切換。
  * 卡片採用**玻璃擬物化 (Glassmorphism)** 風格，使用 `backdrop-filter: blur(15px)` 搭配半透明白色邊框，營造精緻、具層次感的輕量視覺。

### 排版與字體優化
* 載入了 Google Fonts `Fredoka`、`Noto Sans TC`（思源黑體）與 `Outfit`。
* `Fredoka` 提供了童趣的圓角英文數字，`Noto Sans TC` 則確保了台語漢字與羅馬拼音在各種不同瀏覽器上都能清晰可讀。

### 微互動動畫
* **地圖火車動畫**：當計算起訖站旅程時，火車圖示會循序沿著環島鐵路節點前行。每次移動都有微幅的抖動與向上升起的蒸汽煙圈動態，極具童趣。
* **時鐘回彈與反饋效果**：設置預設時間時，時鐘會觸發 `bounce-effect`（回彈動畫）；答對問題時觸發 `triggerConfettiParticles` 灑落紙花，答錯則觸發 `shake`（搖晃卡片），給予使用者直覺且有趣的即時反饋。

### 行動端響應式介面 (RWD) 與觸控操作優化 (2026-06-27 更新)
* **標題與按鈕群組防溢出**：新增對網頁頂部標頭、檢定關卡選擇鈕（`.quiz-select-btns`）及時鐘微調按鈕在窄螢幕下的自動折行或垂直堆疊設定，杜絕了水平方向的溢出與破版。
* **版面網格自動摺疊與地圖百分比縮放**：
  * 起訖點選擇、地圖、時鐘以及大檢定挑戰，在小於 900px（平板）與小於 600px/500px（手機）時，會由兩欄式排列自動改為單欄流線佈局。
  * **地圖與火車等比例縮放**：原本 SVG 地圖與火車軌跡定位使用固定 `320px` 像素，在極窄的手機螢幕（如 iPhone SE）上會超出卡片邊界。我們將地圖修改為 `width: 100%` 自適應寬度與 `aspect-ratio: 320 / 500` 等比例縮放，且將火車的 `left`/`top` 動態位置計算改為 **「百分比比例定位 (Percentage-based Positioning)」**，確保不論地圖在任何尺寸下縮小，火車圖示依然能與鐵道節點 100% 精準對齊、絕不跑偏。
* **導覽列水平滾動**：在手機版下，導覽分頁鈕會自動轉化為水平滑動選單，防止項目擠壓，保持舒適的單手點擊體驗。
* **原生觸控與拖曳手勢**：時鐘採用原生 `Pointer Events` 結合 `setPointerCapture` 手勢捕捉，完美支援行動裝置之手指拖曳，觸控操作靈敏且不易因手指移開鐘面而中斷。
* **觸控視覺優化**：加入 `-webkit-tap-highlight-color: transparent`，消除行動裝置點擊卡片與按鈕時產生的突兀底色閃爍，大幅提升介面精緻感。

## ⚙️ 2. 核心邏輯與演算法優化

### 環島鐵路雙向路徑計算
* 為了擴展至**全台城市 (14 站)**，環島鐵路形成了一個閉合的圓環。
* 傳統的順序距離相減無法處理跨越「宜蘭 ↔ 基隆」等臨界點的計算。
* 在 `app.js` 中實作了**環島雙向最短路徑演算法**：
  1. 順時針累加各相鄰站點間距。
  2. 逆時針累加各相鄰站點間距。
  3. 比對兩者距離，挑選較短者作為推薦行車路線，動態繪製 SVG 軌道路徑，並顯示順時針或逆時針的方向提示。

### 時鐘角度換算與微調按鈕
* 為解決滑鼠/手指在觸控螢幕上直接拖曳時針、分針可能造成的定位誤差或挫折感，時鐘拖動機制設有「5分鐘」的自動 Snap（吸附磁貼）功能。
* 額外新增了四個**時間微調按鈕 (Adjust Buttons)** 與六個**常見發車預設值 (Presets)**，大副提昇了不同年齡層學童操作時的無障礙性與便利性。

## 🔊 3. 台語語音引擎 (TTS) 健壯性與口語化優化

### 台語道地口語說法與文法修正 (2026-06-23)
* **問題**：原發音使用國語直譯台語字（如「下午」讀 hā-ū、「元」讀 goân、「一共」讀 ı̍t-kiōng），聽起來極為僵硬不自然，且會出現「第兩月台」這類不合台語語法的錯誤詞彙。同時原價格朗讀不支援 $1000 以上的數值。
* **優化方案**：
  * **口語化轉換**：將時間代稱「早上/下午/晚上」改為台語口語的「早起 (tsá-khí) / 下晡 (ē-po͘) / 暗時 (àm-sî)」。
  * **量詞與代稱優化**：將票價計量「一共...元」修訂為台語道地的「攏總 (lóng-chóng)...箍 (kho͘)」。
  * **序數修正**：另外設計 `ordinalToTaigiText` 處理月台與車廂等序數，強制將 platform 2 轉化為「第二月台 (tē-jī gue̍h-tâi)」以修正「第兩月台」的語音錯誤。
  * **千位金額支持**：重構 `costToTaigiText` 以支援千位數讀音，當票價累計超過一千元時，能正確發出如「兩千七百五十箍 (nn̄g-tsian tshit-pah gōo-tsa̍p kho͘)」的正確語音。

### 教育部真人發音音檔拼接與本地備援引擎 (2026-06-23 重大更新)
* **背景與挑戰**：原本預期使用的 Google Translation TTS (`tl=nan`) 已被 Google 伺服器關閉，在調用時一律回傳 `400 Bad Request`，導致先前網頁在各平台下皆強制降級至國語同音字備援，聽起來是不自然的華語拼音。
* **重構方案**：
  * **真人發音庫串接**：改為串接由 ChhoeTaigi 社群開源維護的教育部《臺灣台語常用詞辭典》官方真人發音鏡像庫 [KipSutianDataMirror](https://github.com/ChhoeTaigi/KipSutianDataMirror)，並在 `app.js` 中建立一組完整的常用台語詞彙、車站、數字及時間漢字對應音標 ID 映射表。
  * **動態語音拼接與佇列播放**：實作非同步音訊播放佇列播放器 `playAudioQueue`，將起訖站、張數、車次、發車時間、總票價與月台等複雜語句拆解後依序異步加載播放真人錄製的 mp3 音訊（例如將 15:30 發車的「下晡三點半」拆解為 `下晡`、`三`、`點`、`半` 四個實體音檔，以 `playbackRate = 0.85` 的合適語速流暢播出），徹底解決語音發音不正確與 API 400 錯誤。
  * **本地同音字備援優化**：如果處於斷網或音檔加載失敗狀態，系統會自動降級至 Web Speech API (`zh-TW` 語音)，並進一步優化了 `twHomophones` 對照表，使擬真拼音語音在離線時能更加逼真。
  * **自訂語速調節功能 (2026-06-27 更新)**：
    * **語速自由拉動**：在網頁頂部導覽控制區加入了「語速調節滑桿 (Speech Rate Controller)」，使用者可在 `0.5x`（慢速學習）至 `1.5x`（快速口語）之間自由調整發音速度，調整間距為 `0.1x`。
    * **多引擎速率同步**：語速調整會即時且同步地套用於教育部官方真人發音播放器（透過設定 `HTMLMediaElement.playbackRate`）與本地 SpeechSynthesis 語音合成引擎（設定 `SpeechSynthesisUtterance.rate`）。
    * **語速設定持久化**：語速設定會寫入瀏覽器 `localStorage` 的 `app_speech_rate` 中，下次開啟網頁時會自動載入偏好語速，提升學習體驗。

## 🏆 4. 遊戲機制與資料持久化 (Persistence)

* **集章冊解鎖邏輯**：隨機在挑戰成功後釋放「尚未解鎖」的縣市印章，避免重複解鎖降低使用者的收集動力。
* **LocalStorage 持久化儲存**：
  * 使用者的**集章進度**（解鎖的車站印章列表）與**偏好語言**、**偏好主題**皆會寫入瀏覽器的 `localStorage` 中。
  * 當使用者重新整理網頁、關閉瀏覽器再次開啟時，已解鎖的紀念章與網頁語言、主題設定均會完美保留，增強了本學習應用的完整度與實用性。
